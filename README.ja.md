# TONE OS ビルドスクリプト

[English → README.md](README.md)

**TONE OS の ISO を、ゼロから作る**ためのスクリプトです。Ubuntu 24.04(noble)ベース・KDE Plasma・日本語専用・amd64。
このリポジトリには**ビルドスクリプトだけ**が入っています。**ISO は配布しません。** 必要なものは、あなたがビルドを実行したときに、各公式サイトから取得されます([THIRD_PARTY.md](THIRD_PARTY.md) を参照)。

> ## ⚠ 状態: 試験版(最後までの確認は未完了)
> 生成されるファイルの単体テストは通っていますが、**この公開版でのISO全体のビルドは、まだ最後まで確認できていません。**
> 実験的なものとしてお使いください。ご報告は歓迎します(「ご連絡」を参照)。

> ## ⚠ 実行する前に
> - スクリプトは長く(約6,000行)、**管理者権限(`sudo`)で動きます。** 先に**中身を読んで**、仮想マシンか予備のPCで試してください。
> - ディスクを勝手に初期化することはありませんが、大きな作業フォルダを作り、イメージのマウント・解除を行います。先にバックアップを取ってください。
> - 無保証です(MIT ライセンス)。

## 必要なもの

- ビルドするPC: Ubuntu 24.04 かその派生(作者は Zorin OS 18 で作成)、**amd64**
- インターネット接続
- 作業フォルダ(既定 `/home/TOSE`)に **35 GB 以上の空き**
- 時間: 作者の環境で約30分(ネットワークとCPUによります)

## 使い方

```bash
sudo bash build-tone-os.sh
```

- 出力(ISO・使用説明書PDF・ソースZip): `/home/TOSE/out`
- 途中で、任意のファイル選択画面(スタートページ `index.html`、起動音・終了音、壁紙パック)が出ることがあります。**キャンセルすれば標準のものを使います。**
- 環境変数はスクリプトの先頭に書いてあります(例: `MAX_ATTEMPTS`、`KEEP_WORK=1`)。

## ビルドする前に: 更新サーバーを自分のものにする

この公開版には、**更新サーバーは設定されていません。** 更新の取得先と壁紙の取得先は、仮の `https://updates.example.invalid/tos/` になっています。
署名つきの更新の仕組みを使うには、自分のサーバーを用意して、この値を変えてください(スクリプト内で `updates.example.invalid` を検索)。そのままなら、更新は見つからないだけで、害はありません。

## 作者の非公開版との違い

この版は、AIアシスタント関連の部品を取り除き、メールアドレスを使い捨ての連絡先に、作者のサーバーのアドレスを仮のものに置き換えてあります。非公開のスクリプトから自動で生成しています。
