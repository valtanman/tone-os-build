# Security Policy / セキュリティ方針

## Reporting a vulnerability / 脆弱性の報告

Please **do not open a public issue** for security problems.
Use GitHub's **"Report a vulnerability"** button on the *Security* tab (private vulnerability reporting).
If that is not available, send a short message to **toneappbildman@appmail.uk** (disposable contact address).

セキュリティ上の問題は、**公開のIssueに書かないでください**。
*Security* タブの **「Report a vulnerability」** から、非公開で報告してください。
使えない場合は、**toneappbildman@appmail.uk**(使い捨ての連絡先)に短く連絡してください。

## Scope / 対象

This script runs as root and builds a bootable OS image. Especially welcome: ways to make it write outside its work folder, to download or run unverified code, or to leave credentials or personal data inside the built image.
このスクリプトは管理者権限で動き、起動可能なOSイメージを作ります。次のような報告は特に歓迎します: 作業フォルダの外に書き込ませる方法、検証されていないコードを取得・実行させる方法、認証情報や個人情報がイメージに残る問題。

## Supported versions / 対象の版

Only the latest version. / 最新の版のみ。
